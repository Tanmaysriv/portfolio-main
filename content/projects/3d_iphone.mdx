# 3D iPhone E-Commerce

## Interactive iPhone Product Experience

This project is a modern e-commerce experience designed around the iPhone 15 Pro.

It combines interactive 3D scenes, video content, animations, and responsive layouts to create an immersive product showcase.

## Overview

The application focuses on presenting the iPhone as an interactive digital product rather than a traditional static product page.

Users can explore product sections, watch promotional videos, interact with 3D content, and view pricing in Indian Rupees.

## Features

- Interactive product showcase
- iPhone 15 Pro presentation
- 3D product experience
- Three.js rendering
- React Three Fiber
- Video carousel
- GSAP animations
- Responsive design
- Mobile optimization
- INR pricing
- Error monitoring

Installation

Clone the project:

git clone https://github.com/yourusername/iphone-main.git

Navigate into the project:

cd iphone-main

Install dependencies:

npm install

Start development:

npm run dev

The application will normally be available at:

http://localhost:5173

Customization
Pricing

Product pricing can be modified inside the relevant product components.

Media

Images and videos can be placed in the project's asset folders.

Update the corresponding imports when replacing assets.

Production Build
npm run build
