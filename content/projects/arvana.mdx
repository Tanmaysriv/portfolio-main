# ARVANA

## AR Virtual Try-On E-Commerce Platform

ARVANA is an AR-powered e-commerce platform that allows customers to virtually try products before purchasing.

The platform combines augmented reality, computer vision, 3D rendering, and modern e-commerce functionality into a single experience.

## Overview

ARVANA supports multiple product categories and provides an interactive camera-based shopping experience.

Users can explore products and experience virtual try-on capabilities using real-time body tracking and 3D visualization.

## Key Features

- Real-time AR try-on
- AI-powered body tracking
- 3D product visualization
- Face detection
- Hand detection
- Pose detection
- Interactive 3D rendering
- Multi-category product experience
- Shopping cart
- Wishlist
- Product management
- Order management
- Seller management
- Payment integration
- Responsive interface

## Supported Products

- Shoes
- Watches
- Clothes

- Jewelry

Installation
git clone https://github.com/Tanmaysriv/ARVANA-pvt.git
cd ARVANA-pvt

Backend
cd backend
npm install

Frontend
cd ../frontend
npm install

Environment Variables

Create:

backend/.env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://localhost:27017/arvana
JWT_SECRET=your-secret-key

Running the Application
Backend
cd backend
npm run dev
Frontend
cd frontend
npm run dev

Challenges
Real-Time Tracking

Maintaining stable product positioning while the user moves was an important challenge.

MediaPipe landmarks are used to calculate the position required by the AR layer.

3D Rendering

Three.js is used to render and manipulate 3D product experiences in the browser.

Performance

Real-time AR processing can be computationally intensive, so the application focuses on efficient browser-side processing.
