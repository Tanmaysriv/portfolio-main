# Ele-Types

## Elegant Typing Experience

Ele-Types is a modern typing test and touch-typing application focused on improving typing speed, accuracy, vocabulary, and consistency.

The application provides multiple typing modes, statistics, themes, sound effects, focus modes, and a QWERTY touch-typing trainer.

## Core Features

### Typing Test

The application supports multiple typing modes.

#### Words Mode

- English Hard
- English Normal
- Chinese Pinyin Hard
- Chinese Pinyin Normal
- 90 second test
- 60 second test
- 30 second test
- 15 second test
- Numbers
- Symbols

#### Sentence Mode

- Chinese sentences
- English sentences
- 5 sentence mode
- 10 sentence mode
- 15 sentence mode

## Typing Statistics

The application tracks:

- WPM
- KPM
- Accuracy
- Correct characters
- Incorrect characters
- Missing characters
- Extra characters
- Visual statistics

## Pacing Modes

### Pulse Mode

The active word receives a visual pulse that helps establish a consistent typing rhythm.

### Caret Mode

A character-level caret provides a traditional typing experience.

## Words Card

Ele-Types also provides a vocabulary learning experience.

Supported vocabulary sources include:

- GRE
- TOEFL
- CET4
- CET6

Features include:

- Multi-chapter selection
- Vocabulary navigation
- Recite mode

## Coffee Mode

Coffee Mode provides a distraction-free free-typing environment.

Users can type anything without following a predefined test.

## QWERTY Trainer

A virtual QWERTY keyboard generates random keys for touch-typing practice.

The trainer provides statistics to help users understand their performance.

## Spotify Player

The application includes an integrated Spotify player for users who prefer music while typing.

Experimental WebGL themes include:

- Tranquiluxe
- Lumiflex
- Opulento
- Velustro

These themes may require additional GPU resources.

## LocalStorage

Important application settings are persisted using browser LocalStorage.

Refreshing the browser preserves supported preferences.

## Focus Mode

Focus Mode simplifies the interface.

It:

- Moves the header toward the footer
- Hides unnecessary settings
- Displays timer and WPM information
- Provides a compact Spotify player when music is enabled

## Ultra Zen Mode

Ultra Zen Mode provides an even more minimal typing environment.

The application can automatically highlight and dim content while the user types.

## Typing Sounds

Available sound effects include:

- Cherry Blue Switch

- Typewriter
