# My Journey into Software Development

My journey into software development started with learning the fundamentals of programming and gradually understanding how code can be used to solve real-world problems.

During my Computer Science (AIML) degree, I developed a strong interest in Data Structures and Algorithms, Object-Oriented Programming, DBMS, Operating Systems and SQL. Solving 450+ DSA problems helped me improve my problem-solving ability and taught me to approach complex problems systematically.

At the same time, I started building web applications using HTML, CSS, JavaScript and React. Projects like To-Do List, Quiz App and Ele-Types helped me understand how frontend development works beyond theory.

As I became more comfortable with development, I started exploring Python, Machine Learning, Deep Learning, Generative AI, Three.js, WebXR and AR/VR.

Projects such as Fraud Detection, Chest X-Ray Diagnosis, StyleSync AI and ARVANA allowed me to combine different technologies to solve different types of problems.

My internships at Techoctanet and AIT Bangkok also helped me understand how development works in practical environments.

Today, my focus is on becoming a stronger software engineer while continuing to explore AI/ML, AR/VR, DevOps and cloud technologies.

My approach to learning remains simple:

**Build → Experiment → Solve → Improve.**
